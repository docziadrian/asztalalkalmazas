# ASZAF - Asztali Alkalmazás

**Közös projekt: docziadrian & Bujáki Erik Attila**

## Leírás

Ez egy Electron-alapú asztali alkalmazás projekt, amely demonstrálja egy egyszerű, keresztplatformos desktop alkalmazás létrehozását.

## Technológiai Stack

- **Electron**: Keresztplatformos desktop alkalmazás keretrendszer
- **Node.js**: JavaScript runtime
- **HTML/CSS/JavaScript**: Frontend technológiák

## Telepítés

1. Klónozd le a repository-t:
```bash
git clone https://github.com/docziadrian/asztalalkalmazas.git
cd asztalalkalmazas
```

2. Telepítsd a függőségeket:
```bash
npm install
```

## Futtatás

Az alkalmazás indítása:
```bash
npm start
```

## Fejlesztés

Az alkalmazás fejlesztése során a következő fájlok a legfontosabbak:
- `main.js` - Az Electron főfolyamat
- `index.html` - Az alkalmazás felhasználói felülete
- `package.json` - Projekt konfiguráció és függőségek
